# mp2-rest-api
The goal of MP2 is to create a FastAPI application built off of the work in MP1 that takes in a csv file, stores its data, and returns rows through HTTP requests. The program starts by returning the application's status and version, before reading and storing the CSV file uploaded by the user. Afterwards, it processes the data using the pipeline created in MP1, raising any errors if they are necessary. After processing the file in accordance with the user's specifications(which files are required, which should be numeric, etc), the API returns the processed data.
